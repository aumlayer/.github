# AUMLayer GitHub org landing — admin checklist

Complete these in the GitHub UI (org **Owners**) for a polished public profile.

## Done via automation

- [x] Organization profile README — [profile/README.md](profile/README.md) in [aumlayer/.github](https://github.com/aumlayer/.github)
- [x] Org short description (API)
- [x] Public [aumlayer/security-labs](https://github.com/aumlayer/security-labs)

## Recommended in GitHub UI

1. **Profile picture** — [Organization settings → Profile](https://github.com/organizations/aumlayer/settings/profile)  
   Upload [`assets/aumlayer-logo.png`](assets/aumlayer-logo.png) (RGBA, transparent background). Replaces the default identicon in link previews and the org header.

2. **Social / contact** — same Profile page  
   - **Website** (e.g. marketing site or `https://github.com/aumlayer/security-labs`)  
   - **Location** (optional)  
   - **Email** (optional public contact)

3. **Pin repository** — [github.com/aumlayer](https://github.com/aumlayer) → **Customize pins**  
   Pin **security-labs** (and unpin when you add a newer flagship public repo).

4. **Public members** — [People settings](https://github.com/organizations/aumlayer/settings/profile)  
   Allow **Public** membership for core team (adds credibility on the sidebar).

5. **Repository social preview** — `security-labs` → Settings → Options → Social preview image  
   Upload 1280×640 banner (PHP2Shell / ENGINE visual).

6. **Enable security features** — Org → Settings → Code security  
   Secret scanning + push protection on public repos.

7. **About security-labs** — ensure **Releases** or **Tags** when you cut `php2shell-v1.0` milestones.

## Verify

- Open https://github.com/aumlayer in a logged-out window — you should see the profile README and **security-labs** under Repositories.
